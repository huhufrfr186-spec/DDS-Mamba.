# DDS-Mamba 方法说明

DDS-Mamba 通过独立的位置状态与外观状态进行视觉跟踪，结合空间门控、可靠度控制更新、可靠度过滤记忆和 Kalman 运动预测。

## 编码器与状态分支

| 模块 | 配置 |
| --- | --- |
| 空间编码器 | 冻结 MAE ViT-B/16，输出维度 768 |
| 身份编码器 | 冻结 DINOv2 ViT-S/14，输出维度 384 |
| 裁剪尺寸 | 模板 128×128，搜索 256×256，身份 224×224 |
| 搜索投影 | 768→256，模板均值产生尺度与偏置 |
| 模板调制 | `x * (1 + tanh(scale)) + bias` |
| 空间编码 | 固定二维正弦余弦位置编码，行优先 patch 顺序 |
| 位置分支 | 2 个 token，2 层 Mamba，使用第二个输出 |
| 外观分支 | 258 个 token，4 层 Mamba，使用最终上下文输出 |
| Mamba | state 16、expand 2、dt rank 16、conv 4 |
| 框预测 | 两层 256 维 GELU MLP，归一化 cxcywh |
| 置信图 | 外观分支的空间输出与最终 token 拼接后线性投影 |

模板在初始化时编码并缓存。位置状态由模板均值的学习投影初始化，外观状态由初始身份特征的学习投影初始化并进行 L2 归一化。每个搜索裁剪独立执行 Mamba 扫描。

## 空间门控与记忆

门控为 `g = Π_G[1 + 0.5 * (256 * softmax(z) - 1)]`。可行域满足每项位于 `[0.5, 1.5]`，且总和为 256；反向传播使用自由变量集合上的解析 Jacobian。

RFMB 容量与检索 top-K 均为 5。条目效用为 `U = w * exp(-0.01 * age)`，检索使用相似度的 softmax 加权聚合。每帧记忆老化一次；写入时替换最低效用条目。身份分数由初始参考和记忆相似度共同计算。

## 可靠度控制器

QACU 更新率为 `ρ = min(0.95, u_map * κ)`。所有硬门通过后提交位置状态，并对混合外观状态归一化。轨迹可靠度更新为 `μ = 0.9 * μ + 0.1 * ρ`，初值为 1，达到 0.70 时写入 RFMB。

| 控制参数 | 数值 |
| --- | --- |
| map / peak / identity 门限 | 0.45 / 0.50 / 0.60 |
| agreement / update-rate 门限 | 0.25 / 0.35 |
| Kalman 创新门限 | 9.49 |
| active 搜索尺度 | 4 |
| lost 运动/最近框搜索尺度 | 8 / 8 |
| 模板上下文尺度 | 2 |
| 进入 lost 的连续弱帧数 | 3 |
| 恢复确认的连续候选数 | 2 |
| 恢复 IoU / 身份一致性门限 | 0.50 / 0.65 |

裁剪边长为 `scale * sqrt(w * h)`。第三个连续弱 active 帧输出运动预测，下一帧进入 lost。lost 候选连续满足位置与身份一致性后确认恢复；恢复刷新位置状态，保留外观状态、可靠度和更新历史，记忆仅老化。

Kalman 使用归一化中心、对数宽高及其速度构成 8 维状态。固定过程噪声为 `diag(1e-4,1e-4,1e-5,1e-5,1e-3,1e-3,1e-4,1e-4)`，测量噪声为 `diag(1e-3,1e-3,5e-4,5e-4)`；协方差更新采用 Joseph 形式。

## 训练与损失

初始化帧之后连续展开 16 个更新帧。在线控制器生成搜索区域；标签用于损失和辅助裁剪，持久状态由控制器管理。选中分支与 QACU 保留跨帧梯度，离散选择与记忆条目停止梯度。

损失包含框回归、focal 置信图、位置/外观去相关、时间一致性、身份一致性、范数约束和中心对齐。框损失为 `5 * L1 + 2 * (1 - GIoU)`；focal 使用 `(1-Y)` 负项与 gamma 2。辅助损失系数为 0.1，范数系数为 0.01，各帧损失按完整 clip 长度平均。

teacher 概率在前 20 轮按半余弦计划降至零。teacher 与负样本分支读取停止梯度的状态和上下文，不提交状态。同帧负样本采用与目标不相交的同尺度裁剪。

训练默认使用 896 个训练序列与 224 个验证序列，每轮 8960 个 clip，40 轮，batch size 1，AdamW 学习率 2e-4、权重衰减 1e-4，预热 5 轮后余弦衰减，梯度裁剪 1。种子为 2024、2025、2026。

增强包括尺度 `[0.8,1.2]`、裁剪宽度 0.2 以内的平移、亮度/对比度/饱和度 ±0.2，以及概率 0.5 的水平翻转。一个 clip 共用颜色与翻转参数，搜索区域逐裁剪执行几何 jitter。

验证选模计算原始输出框的 IoU 积分，逐序列等权平均并排除初始化帧。基准评估流程见 [评估接口](OFFICIAL_EVALUATION.md)。
